# Trendora

Trendora is a polished full-stack fashion & lifestyle shopping experience built with React, Bootstrap, custom CSS, Express and MongoDB-ready APIs.

## Stack

- Frontend: React + Vite + JSX
- Styling: Bootstrap 5 + custom CSS
- Icons: Bootstrap Icons
- Animations: CSS keyframes + IntersectionObserver reveal animations
- Backend: Node.js + Express
- Database: MongoDB via Mongoose
- API: REST endpoints for products, categories and orders
- Fonts: Google Fonts (Plus Jakarta Sans + Playfair Display)
